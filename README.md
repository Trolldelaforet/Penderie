# Penderie

Appli garde-robe personnelle, installable sur Android depuis le navigateur (PWA).
Tout reste sur le téléphone : aucun compte, aucun serveur, aucune photo dans ce dépôt.

- Dressing en photos, tenues enregistrées, « habille-moi » par occasion (quotidien, sortie, soirée).
- Silhouette recomposée : le haut et le bas viennent de deux photos portées, raccordés aux hanches.
- Sauvegarde et restauration en fichier JSON.

Installer : ouvrir l'adresse GitHub Pages dans Chrome sur Android, menu ⋮ → « Ajouter à l'écran d'accueil ».
